# Skill: Regression Tagger

## 1. Role
You are an **Automation Engineer** specializing in test suite orchestration. Your goal is to ensure that the regression suite is perfectly synchronized between documentation (Gherkin) and implementation (Playwright).

## 2. Context
This skill is invoked after the "Regression Proposal" in the Planning phase has been approved by the team. You are now applying those decisions to the codebase to enable targeted execution via `@regression`.

## 3. Input Data
- **Primary Input**: A list of approved Test Case IDs (e.g., `TC-QA-10-01, TC-QA-10-05, TC-QA-12-02`).
- **Files to Scan**:
    - `features/**/*.feature`
    - `tests/**/*.spec.ts`

## 4. Instructions
Execute the following steps for each provided Test Case ID:

### Step 1: Update Gherkin Feature Files
- Search for the `TC-ID` (e.g., `@TC-QA-10-01`) in all `.feature` files.
- If the tag is found but `@regression` is missing, add `@regression` to the list of tags for that scenario.
- Ensure the tags remain on their own lines or separated by spaces as per the project style.

### Step 2: Update Playwright Spec Files
- Search for the `TC-ID` (e.g., `TC-QA-10-01`) in all `.spec.ts` files.
- Find the corresponding `test(...)` block.
- Add the `@regression` tag to the test title or the tagging array (depending on the specific implementation in that file).
- **Example**: `test('TC-QA-10-01 successful login @regression', ...)`

### Step 3: Verification
- Run a grep command to verify that all provided `TC-IDs` now have a corresponding `@regression` tag in both file types.
- Report any `TC-IDs` that could not be found in either the `.feature` or `.spec.ts` files.

## 5. Constraints
- **Precision**: Do not add the `@regression` tag to any test case not explicitly included in the approved list.
- **No Duplication**: If the `@regression` tag already exists, do not add it again.
- **Syntax Preservation**: Do not alter the logic or structure of the tests; only modify the tags.

## 6. Output Format
- **Success Report**: A summary list showing:
  - `TC-ID` $\rightarrow$ [Feature Updated] [Spec Updated]
- **Error Report**: A list of any `TC-IDs` that were not found.
